Recent changes (25.10.2026)
- Fixed compilation with FastLED 3.10 and ESP8266 Arduino core 3.1.x
- Moved web interface storage from deprecated SPIFFS to LittleFS (file system image must be uploaded again)
- Firmware & Wi-Fi page, Filesystem editor and Arduino OTA uploads are now password protected
- Wi-Fi password is no longer shown on this page or sent by the /wifi endpoint
- Settings are saved to EEPROM 3 seconds after the last change instead of on every slider movement, reducing flash wear
- Fixed Sinelon and Juggle effects writing past the end of the LED strip
- Values sent to the controller are now limited to their valid ranges
- Fixed autoplay stopping after ~49 days of uptime
- Changes made on another device now also update the solid color picker and visible controls
- Updated firmware export instructions on Firmware & Wi-Fi page for Arduino IDE 2
- Web interface moved to Bootstrap 5.3 (Bootswatch Flatly theme) and jQuery 4.0, MiniColors updated to 2.3.6, Ace editor to 1.44.0
- Removed web fonts (Google Fonts and Glyphicons): pages use system fonts and inline icons, and load without internet access
- Removed Isotope library, Simple mode grids use CSS layout now
- Dark theme by default, switch between dark and light theme with the sun / moon button in the navigation bar
- Brightness is shown in percent (0-100 %), autoplay duration in seconds
- Admin credentials moved to secrets.h (not stored in the public repository), see secrets.example.h
- Web server can serve gzip compressed files: when only file.js.gz exists it is sent for file.js
