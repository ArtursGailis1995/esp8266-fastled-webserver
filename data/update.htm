Update firmware

Over the network from Arduino IDE: go to Tools > Port, choose this controller from the Network ports list and click Upload. The IDE will ask for the admin password (ADMIN_PASSWORD in secrets.h).

Firmware file for this page: in Arduino IDE 2 click Sketch > Export Compiled Binary (Alt + Ctrl + S). The file is saved inside the sketch folder as build/esp8266.esp8266.nodemcuv2/esp8266-fastled-webserver.ino.bin. Click Sketch > Show Sketch Folder to open it quickly.

File system file for this page: the web interface is stored in a LittleFS image built from the data folder. Create it with the mklittlefs tool, which is installed together with the ESP8266 board package (on Windows: %LOCALAPPDATA%\Arduino15\packages\esp8266\tools\mklittlefs). Run it in the sketch folder; these values are for the default 4MB (FS:2MB OTA:~1019KB) flash layout:

mklittlefs -c data -p 256 -b 8192 -s 2072576 littlefs-4M2M.bin

To upload the file system over USB instead, install the arduino-littlefs-upload plugin and run Upload LittleFS to Pico/ESP8266/ESP32 from the command palette (Ctrl + Shift + P). Close the Serial Monitor first.

To keep the file system contents when updating over USB, make sure Tools > Erase Flash > Only Sketch is selected in Arduino IDE!

The controller restarts after each update. After a file system update, refresh this page with Ctrl + F5 so the browser does not show old cached files.

Reset Wi-Fi settings

Wi-Fi settings can be reset in case you need to connect the controller to a different network or your Wi-Fi password has changed. Resetting enables access point mode and lets you repeat the initial configuration.

Instructions:

  1. Reset settings below
  2. Connect to the ESP8266-XXXX Wi-Fi network on your smartphone or computer (XXXX is the end of the controller MAC address, see Information page)
  3. Go to http://192.168.4.1 (should open automatically) and enter your Wi-Fi information
  4. Power cycle the controller if needed
